问题

诚实的答案

它是真的免费，还是免费到某个时候为止？

这次构建里没有账号、没有 API Key、也没有额度系统——以后也没有需要关闭的东西。 模型来自公开发布的免费层，应用会如实呈现它们：某个模型不再免费时， 那一行会停止回答，而不是给你寄一张账单。

为什么 macOS 在打开前会警告我？

这个 .dmg 是在一台笔记本上构建的，没有公司签名和公证—— 那需要一个 Apple 开发者账号和一条这个项目还没付费的流水线。 首次打开请右键应用 → 打开，之后 Gatekeeper 就不再管它。

运行它需要什么？

一台 macOS 12 或更新版本的 Apple 芯片 Mac，以及 OpenCode—— 就是那个用本地服务回答免费模型的应用。FreeCode 会自己启动这个服务； 如果还没装 OpenCode，第一次免费对话会明确告诉你，而不是悄悄失败。 这里的下载包是 9 MB，装到磁盘上是 16 MB，因为它是一个 Rust 宿主， 直接画进系统自带的网页视图，而不是自带一份 Chromium。Windows 版正在做，还不能用； 页头的按钮如实这么说，而不是撒谎。

它会毁掉我的文件吗？

它只在你选定的文件夹里工作，不碰外面的一切。每一次改动都是审阅面板里能读的差异块， 一次运行会保留改动前的镜像，所以撤销能把文件夹还原成原样——包括它新建的文件。

它会偷偷上传数据吗？

没有分析、没有崩溃上报、没有使用信标——设置里的那一行写着“尚未构建”，因为它确实没有。 离开你机器的只有这次运行的文本，发给正在回答它的模型服务，以及它打开的页面。

在飞机上能用吗？

不能。这次构建里的每条路线都要走网络：免费模型是云端的一层， 你粘贴在设置里的密钥也指向远端。没有可以离线兜底的已下载模型——这次构建一个也没有。

为什么用 Rust 而不是 Electron？

因为循环本身就是产品。工具运行器、补丁应用器、浏览器桥接和差异引擎都是原生代码， 所以一次运行把时间花在思考上，而不是重画窗口。
