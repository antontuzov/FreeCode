Questions

The honest answers

Is it actually free, or free until it isn't?

There is no account, no API key and no credit system in this build — nothing to turn off later. The models come from a published free tier, and the app shows them as they really are: when one stops being free, the row stops answering rather than sending you an invoice.

Why does macOS warn me before it opens?

The .dmg is built on a laptop, not signed and notarised by a company — that is an Apple Developer account and a pipeline this project has not paid for yet. Right-click the app → Open the first time and Gatekeeper leaves it alone after that.

What do I need to run it?

An Apple silicon Mac on macOS 12 or newer, and OpenCode — the app whose local service answers the free models. FreeCode starts that service itself; if OpenCode is not installed yet, the first free turn says so instead of failing silently. The download here is 9 MB and the installed app is 16 MB on disk, because it is a Rust host drawing into the system's own web view rather than a bundled Chromium. Windows is next and not ready; the button in the header says so rather than lying.

Can it wreck my files?

It works in a folder you picked, and nothing outside it. Every change is a hunk you can read in the review panel, and a run keeps a before-image journal, so reverting puts the folder back the way it was — including files it created.

Does it phone home?

No analytics, no crash reporting, no usage beacon — that row in Settings says "not built" because it isn't. What leaves your machine is the text of the run, to whichever model service is answering it, and the pages it opens.

Will it work on a plane?

No. Every route in this build answers over the network: the free models are a cloud tier, and a key you paste in Settings points at a remote endpoint too. There is no downloaded model to fall back on — this build has none.

Why Rust and not Electron?

Because the loop is the product. The tool runner, the patch applier, the browser bridge and the diff engine are native code, so a run spends its time thinking rather than redrawing a window.
